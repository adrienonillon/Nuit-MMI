# Nuit MMI 2027

Site de la Nuit MMI 2027 (SAE 501) : site « piraté » à déverrouiller, site restauré, accueil et règlement.

## Lancer en local

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` : serveur de développement
- `npm run build` : build de production (`dist/`)
- `npm run build:single` : build en un seul fichier HTML (`dist-single/`)
- `npm run preview` : prévisualiser le build

Le site est publié automatiquement sur GitHub Pages à chaque push sur `main`.
